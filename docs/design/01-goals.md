# scorarium goals

Scorarium is a tool to answer the question "Do I have the sheet music for this piece?". A secondary
goal is to be a searchable database of the sheet music (and books) that I own. Book support is a
happy accident, but it is not a primary goal.

Scorarium is intended to be self-hosted (and easy to do so) for a personal library of both physical
and digital sheet music. The catalog will be public (read-only, overridable per-publication), but
the hosted assets (PDFs, EPUBs) and user data (notes, tags, playability) will be private.

Scorarium does not need to be multi-user, mobile friendly, notation rendering, or even have a
good-looking UI. It is not intended to be used for performing music, but rather cataloging and
searching through a sheet music library.

I want cataloging to be easy, and I want searching to be easy. Importantly, I want to search not
just the "publication"s (the physical or digital book) but also the "work"s (e.g., Op. 28, No. 2)
contained in the publications.

I also want to be able to track my own relationship with the works through tags, notes, and
playability.
